
# babel-preset-transform-ui5

[Docs](../../README.md)

This package is ESM-only. Load the preset through an ESM import; CommonJS `require()` is not supported.

## Requirements

- **Node.js `^22.18.0 || >=24.11.0`**.
- **Babel 8** (`@babel/core` 8.x).

## Install

```sh
npm install babel-preset-transform-ui5 --save-dev
```

or

```sh
yarn add babel-preset-transform-ui5 --dev
```
