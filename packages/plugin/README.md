
# babel-plugin-transform-modules-ui5

[Docs](../../README.md)

There is also a preset which should be used rather than using the plugin directly.

## Requirements

- **Node.js ≥ 20.19**. See the [Node.js support policy](../../CONTRIBUTING.md#nodejs-support-policy) for how we evolve this floor.
- A Babel 7 toolchain (`@babel/core` 7.x) — the plugin is declared as a peer of `@babel/core`.

## Install

```sh
npm install babel-plugin-transform-modules-ui5 --save-dev
```

or

```sh
yarn add babel-plugin-transform-modules-ui5 --dev
```
