
# babel-plugin-transform-modules-ui5

[Docs](../../README.md)

There is also a preset which should be used rather than using the plugin directly.

This package is ESM-only. Load the plugin through an ESM import; CommonJS `require()` is not supported.

## Requirements

- **Node.js `^22.18.0 || >=24.11.0`**. See the [Node.js support policy](../../CONTRIBUTING.md#nodejs-support-policy).
- **Babel 8** (`@babel/core` 8.x), declared as a peer dependency.

## Install

```sh
npm install babel-plugin-transform-modules-ui5 --save-dev
```

or

```sh
yarn add babel-plugin-transform-modules-ui5 --dev
```
